REST API · v1.0

Blood Donation
Health API

A comprehensive RESTful API for managing blood donation requests, donor matching, hospital coordination, and notification workflows.

Format JSON
Auth Bearer JWT
Protocol HTTPS
Base URL
https://api.yourserver.com
🔐

Authentication

All protected endpoints require a JWT Bearer token in the Authorization header.

ℹ Obtain a token via POST /auth/login. Pass it as Authorization: Bearer <token> on every subsequent request.
Request Header
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
⚠

Error Handling

All error responses follow a consistent JSON envelope. Validation errors include a fieldErrors map.

Error Response Schema
{ "timestamp": "2025-05-05T10:00:00", "status": 400, "error": "Bad Request", "message": "Validation failed", "path": "/auth/register", "fieldErrors": { "email": "Invalid email format", "password": "Password must be at least 6 characters" } }
400Validation error — check fieldErrors for per-field messages
401Unauthorized — missing or invalid JWT token
403Forbidden — insufficient role/permissions
404Resource not found
409Conflict — duplicate resource (e.g., existing profile)
